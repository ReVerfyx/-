# Последний бастион — Android 0.1

Самостоятельная офлайн 2D RTS по мотивам механик строительства и осады, знакомых по Diplomacy Is Not an Option. Это первая игровая версия, не официальный порт и не копия PC-игры. Код и процедурная графика созданы для проекта; чужие игровые файлы не используются.

## Что реализовано

- Изометрическая карта 32 × 32, перемещение камеры пальцем, масштаб кнопками.
- Цитадель, дома, лесопилки, карьеры, фермы, казармы, стены и башни.
- Дерево, камень, еда, лимит армии от домов. Добыча автоматическая, без отдельных рабочих.
- Два типа своих войск: мечники и лучники. Выбор всей армии и приказ движением по касанию карты.
- Десять волн врагов с четырёх направлений; с третьей волны появляются тяжёлые бойцы.
- Автоматическая стрельба башен и цитадели, разрушение строений, ремонт и три уровня зданий.
- Пауза с возможностью строить, скорость 1×/2×, победа и поражение.
- Автосохранение каждые 15 секунд во время игры, после волн и при сворачивании.
- Необязательные синтезированные звуки. Интернет приложению не нужен.

## Быстро проверить без APK

Откройте `app/src/main/assets/index.html` в современном браузере на компьютере. Игра автономна, сервер и внешние файлы не нужны. На Android открытие локального HTML зависит от браузера и файлового менеджера; надёжный вариант — APK.

## Собрать APK через GitHub Actions с телефона

1. Распакуйте ZIP. Внутри папки `last-bastion` находятся исходники.
2. Создайте репозиторий на GitHub. Загрузите **содержимое** этой папки в корень репозитория: `app`, `settings.gradle`, `build.gradle` и остальные файлы. Не загружайте один ZIP вместо исходников.
3. Обязательно добавьте файл `.github/workflows/android.yml`. Если файловый менеджер скрывает папку `.github`, включите показ скрытых файлов или создайте этот путь через GitHub → Add file → Create new file и вставьте содержимое файла из архива.
4. Откройте вкладку **Actions → Build Android APK → Run workflow**. Workflow также запускается при push в `main`/`master`.
5. После зелёного результата откройте запуск. Внизу, в **Artifacts**, скачайте `Last-Bastion-APK`.
6. Распакуйте скачанный архив и установите `app-debug.apk`, разрешив установку из этого источника.

Требования: Android 6.0+ и современный Android System WebView. На старых WebView используемый JavaScript может не работать: Android 6 сам по себе не гарантирует совместимость. На реальном устройстве производительность пока не проверена.

Это тестовый APK с debug-подписью. Новая сборка на другом GitHub runner может иметь другую подпись; для обновлений с сохранением данных нужна постоянная собственная подпись. Удаление приложения удаляет сохранение. Release-подпись и публикация в магазине в проект не включены.

## Локальная сборка

JDK 17, Gradle 8.9, Android SDK Platform 35 и Build Tools 34.0.0. Укажите SDK через `ANDROID_HOME` либо `local.properties`, затем из корня:

```sh
gradle --no-daemon :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.
Gradle Wrapper не включён: workflow устанавливает фиксированную версию Gradle.
Совместимость версий: https://developer.android.com/build/releases/agp-8-7-0-release-notes
Референс жанра: https://store.steampowered.com/app/1272320/

## Как играть

Начните с лесопилки рядом с деревьями и карьера рядом с серыми камнями. Ферма уже построена; она производит еду. Затем постройте казарму, коснитесь её и нанимайте бойцов. Дома повышают лимит армии. Башни ставьте на подходах, а стены — перед ними. Первая волна идёт с северо-запада карты, дальше направления меняются по кругу.

Нажмите здание на нижней панели, затем свободную клетку. Для повторного строительства режим остаётся активным; нажмите ту же кнопку, чтобы отменить. Для лесопилки/карьера нужен ресурс в пределах двух клеток. Нажмите «Все войска», затем точку карты. Повторное нажатие отключает выбор армии. Камера двигается перетаскиванием. Кнопка «Крепость» возвращает её в центр. Пауза позволяет спокойно строить и нанимать. Без еды сила атаки армии снижается.

## Границы версии

Это компактная игровая основа: без полноценной 3D-графики, индивидуальных рабочих, логистики, тумана войны, редактора карт, сложного поиска пути и тысяч врагов. Движение бойцов упрощённое, у плотной застройки возможны заторы. Баланс кампании требует игровых прогонов. Сохранение одно, новая кампания его заменяет. Графика рисуется Canvas; Android-приложение использует встроенный WebView.

APK в данной среде не собран: отсутствует Android SDK. Workflow подготовлен, но запуск на GitHub в рамках этой работы не выполнялся. Результаты доступных проверок находятся в `VALIDATION.md`.
