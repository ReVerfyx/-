# Проверки версии 0.1

Выполнено: `node tests/simulation.cjs` — 12 проверок пройдены.

Проверены преобразование координат, ограничения размещения зданий, добыча ресурсов, найм и лимит армии, ремонт и улучшения, запрет повторного запуска активной волны, атака башен, столкновение врага со стеной и её повреждение, сериализация сохранения, поражение, переход к победе после десяти волн, длительная симуляция без нечисловых координат.

Проверка победы искусственно обнуляет здоровье врагов. Она проверяет переходы состояния, а не баланс или проходимость кампании. DOM и Canvas заменены заглушками; проверки не подтверждают корректную отрисовку или сенсорное управление.

Не выполнены: сборка APK (Android SDK отсутствует), запуск на реальном Android, визуальная проверка (Chromium отсутствует, загрузка установщика завершилась ошибкой), реальный запуск GitHub Actions. Эти ограничения нельзя считать пройденными проверками.
